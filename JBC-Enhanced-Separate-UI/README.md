## How to use

Extract the ZIP, paste the included redesign prompt into your coding assistant, and attach the relevant PNG files. Work page by page if attachment limits apply. Treat these as visual references; use the written prompt for behavior and the actual repository for business rules and data.

Preserve the existing live 3D PC model, assets, controls, labels, and component-selection integration. The PC Builder PNG illustrates the surrounding layout; do not replace the live renderer with an image.

These are design concepts, not screenshots of an implemented website. Use the original logo assets in implementation; generated logo/text variations are not new brand assets. Product imagery, sample fields, and depicted dates are illustrative. Use actual inventory images, customer data, source-defined filters, prices and service inclusions. Keep business/developer notes out of the production UI. The full prompt takes precedence over incidental differences in mockup copy or spacing.
